## Описание
В данной работе проведён рефакторинг кода для соответствия пяти принципам SOLID на основе примеров из методических указаний:
1. **SRP**: Разделение ответственности между `OrderProcessor` и `NotificationService`.
2. **OCP**: Использование интерфейса `Shape` позволяет добавлять новые фигуры без изменения кода `ShapeDrawer`.
3. **LSP**: `Bicycle` больше не наследует `Vehicle`, что устраняет необходимость выбрасывать `UnsupportedOperationException` в методе `startEngine()`.
4. **ISP**: Интерфейсы `Printer` и `Scanner` разделены, чтобы `SimplePrinter` не реализовывал ненужный метод `scan()`.
5. **DIP**: Класс `Computer` зависит от абстракции `Storage`, что позволяет легко подменять `HardDrive` на `CloudStorage`.
